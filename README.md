A practice project exploring **Framer Motion** animations in React — transitions, gestures, and layout animations.

## What's Inside

- Page transitions and animations
- Scroll-triggered animations
- Hover and tap gestures
- Layout animations with `layoutId`
- Staggered list animations

## Tech Stack

- React 19
- Framer Motion 11
- Tailwind CSS 4

## Getting Started

```bash
git clone https://github.com/nagdista-dev/framer-motion-project-1.git
cd framer-motion-project-1
npm install
npm run dev
```

Open `http://localhost:5173`.
